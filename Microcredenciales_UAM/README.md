## Microcredencial 01 · Sesión 03: datos sintéticos y almacenamiento

[Notebook](Microcredencial_01/Sesion_03_Generación_Datos_Sintéticos/DatosSinteticos_notebook.ipynb): creación y generación masiva de datos sintéticos (con `Faker`), uso de funciones generadoras y de distribución, y almacenamiento en distintos formatos y sistemas (ficheros, SQLite, MongoDB):

| Formato | Fichero |
|---|---|
| CSV | [fakeData.csv](Microcredencial_01/Sesion_03_Generación_Datos_Sintéticos/fakeData.csv) |
| JSON | [fakeData.json](Microcredencial_01/Sesion_03_Generación_Datos_Sintéticos/fakeData.json) |
| Parquet | [fakeData.parquet](Microcredencial_01/Sesion_03_Generación_Datos_Sintéticos/fakeData.parquet) |
| Avro | [datosFaker.avro](Microcredencial_01/Sesion_03_Generación_Datos_Sintéticos/datosFaker.avro) |
| Base de datos SQLite | [datosFaker.db](Microcredencial_01/Sesion_03_Generación_Datos_Sintéticos/datosFaker.db) |

**Habilidades:** generación de datos sintéticos · formatos de intercambio y almacenamiento (CSV, JSON, Parquet, Avro, SQL).
