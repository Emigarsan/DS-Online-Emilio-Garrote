# Bloque 03 · Análisis de datos

[← Sprints](../README.md) · [Repositorio](../../README.md)

> El ciclo completo del análisis de datos: extracción desde ficheros, bases de datos SQL, web scraping y APIs; limpieza y transformación (ETL); estadística descriptiva; y visualización con Matplotlib y Seaborn.

**Sprints:** 05–08

## Qué se aprende y qué demuestra

- Procesos ETL y limpieza de datos
- Lectura/escritura de TXT, CSV, Excel, JSON y XML
- SQL (SQLite) y conexión desde Python
- Web scraping (BeautifulSoup) y consumo de APIs
- Estadística descriptiva uni y multivariante
- Visualización con Matplotlib y Seaborn
