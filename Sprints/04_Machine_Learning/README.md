# Bloque 04 · Machine Learning

[← Sprints](../README.md) · [Repositorio](../../README.md)

> Estadística inferencial y Machine Learning con scikit-learn: aprendizaje supervisado (regresión, clasificación, árboles, ensembles, KNN, SVM) y no supervisado (clustering, PCA, selección de características), con evaluación y validación de modelos.

**Sprints:** 09–14

## Qué se aprende y qué demuestra

- Estadística inferencial y probabilidad
- Regresión lineal/logística y regularización
- Árboles, Random Forest, Boosting (XGBoost, CatBoost)
- KNN, SVM, regresión polinómica, balanceo de clases
- Clustering: K-Means, DBSCAN, jerárquico
- Reducción de dimensionalidad (PCA) y selección de features
